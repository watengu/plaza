# plaza — マァスゥ広場（総合掲示板）単独 v0

マァスゥの v2 拡張「広場」を、本体と連携させず単独で公開する最小実装。

- ジャンル板 → スレッド → カード（投稿）。投稿は24時間で表示から消える（TTL）
- 残り時間の表示文法：赤系は残り3時間以内だけ（30分以内は濃い赤地に白字）
- DB: Neon（Postgres）。スキーマは neon/schema.sql、初期データは neon/seed.sql
- エンカ申請はマァスゥ連携後に有効化（v0 では準備中表示）

## 開発
- `npm run build` / `npm run start`
- 環境変数：DATABASE_URL（Neon 接続文字列、サーバ側のみ）
